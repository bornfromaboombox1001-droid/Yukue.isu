# 机いす移動プランナー

年度末・新年度の「机・いすの移動計画」を作るためのアプリです。`index.html` をダウンロードして、パソコンのブラウザ（Edge / Chrome）で開くだけで使えます。インストールは要りません。

## 使い方

1. **教室と机・いす** … 今の教室ごとに、今ある机・いすの数（低規格／高規格）を入力します。来年度その部屋を使う学級名も入力します（例：今の「5年1組」の部屋を来年度は「6年2組」が使う）。学年から規格と高さが自動で決まります。
2. **児童数の入力** … 学級の児童数が決まったら入力します。予備の台数も入れられます。
3. **移動計画** … どの教室からどの教室へ、机・いすを何台運ぶかが自動で出ます。高さの調整が必要なものには「高さを4に」などの指示が付きます。計画表の印刷、Excel用CSVの保存もできます。
4. **貼り紙** … 机・いすに貼る「移動先」の紙を、運び出す教室ごとに印刷できます。
5. **設定・保存** … 題名・日時・注意事項、学年ごとの規格と高さ、データの保存・読み込み、次の年度への引き継ぎ。

## 計算のきまり

- 1〜3年生は低規格（高さ3）、4年生は高規格（高さ4）、5・6年生は高規格（高さ5）。設定で変えられます。
- 低規格は4年生の高さにできないため、低規格と高規格の間では融通しません。
- 余りは、同じ階 → 近い階の不足している教室の順に回します。それでも余る分は保管場所へ運びます。
- 不足が他の教室の余りで埋まらないときは、保管場所・新品から出します。それでも足りない分は「不足（要手配）」と表示します。
- 児童数が未入力の学級は、机・いすを動かさない前提で計算します。

## データについて

入力した内容はブラウザに自動保存されます。別のパソコンで使うときや控えとして、「データをファイルに保存」で JSON ファイルに書き出してください。初期データは令和７年度末の計画表をもとにした仮の数です。実際に数えて直してください。
